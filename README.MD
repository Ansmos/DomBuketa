Добавил экран с избранным. Функционал

1. При переходе по товару он становится просмотренным (горизонтальный RV)
2. Если нажаьб сердечко, он попадает в избранный, чтобы не засорять лишней информацией удаляется из просмотренного, эти итак понятно
3. Если смахнуть избранное (вертикальный RV), он удаляется из избранного, но остается в просмотренном
4. Из любого экрана и по нажатию в любом окне открывается карточка товара, на которой есть кнопка "Избранное"

Добавил напоминание купить товар, напоминание сохраняется в локальную БД, после перезагрузки тоже 
напоминание придет, так как смотрится статус перезагрузки и обновляется нотификация.
При щелчке по нотификации открывается карточка товара
Реализован экран управления уведомлениями, там уведомление можно удалить через swipe либо его изменить
щелчком по кнопке с циферблатом

Создал экран с настройками. Смена темной/светлой темы переключателем, удаление списка просмотренных товаров
Настройки сохраняются в SharedPreferences, настройка применяется сразу, после перезапуска приложения 
тоже применяется
